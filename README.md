# Infrastruktur-automatisering
Mitt eget projekt i kursen Infrastruktur konfigurering och deployment 


## Projektmål

Mitt projekt ska automatisera installation och konfiguration av en webbserver med hjälp av Terraform och PowerShell. Terraform för att skapa katalogstrukturen och Powershell för att installera webbservern, skapa en enkel webbsida och kontrollera att allt fungerar.
